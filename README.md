# 数码产品价签生成器

一个面向手机门店、数码柜台、无人机/智能设备门店、渠道销售和小团队的在线价签/参数牌自动制作工具。

输入产品型号后，系统会根据手机官网、品牌官方商城、产品公开资料等信息生成标准化产品价签，并结合知乎 API 搜索到的全网信息做辅助验证，帮助门店快速制作可打印、可导出、可复用的商品展示牌。

项目定位不是单一手机工具，而是面向市面上各类数码产品的价签制作工作流：手机、平板、耳机、手表、大疆无人机、影像设备、智能硬件等都可以逐步接入统一模板。

## 这个项目解决什么痛点？

很多数码门店在做商品展示时，经常遇到这些问题：

- **价签制作慢**：每个商品都要手动查参数、查价格、排版、截图、打印。
- **信息容易错**：型号后缀相似，例如 `Y500`、`Y500i`、`Y500 Pro`，人工复制很容易混淆。
- **格式不统一**：不同员工做出来的价签风格不一致，影响柜台专业度。
- **批量更新麻烦**：新品上市、价格变化、SKU 版本调整后，要反复手动改。
- **设计门槛高**：不是每个门店都有设计人员，也不是每个人都会 PS 或 AI。
- **品类越来越多**：手机、平板、手表、耳机、无人机、相机、智能硬件都需要不同卖点表达。

本项目希望把这些重复工作自动化：

- 输入型号
- 自动生成产品信息草稿
- 可视化编辑排版
- 一键导出 PNG/PDF
- 直接打印或发给门店使用

## 功能特性

- **型号自动识别**：当前支持 vivo、iQOO、华为、荣耀等机型，后续可扩展到大疆和更多数码品牌。
- **官网数据优先**：价格、SKU、颜色、核心参数以品牌官网/官方商城数据为准。
- **知乎 API 辅助验证**：通过知乎 API 搜索全网相关内容，用于补充卖点和交叉验证信息。
- **静态数据加速**：线上版本优先读取预生成的 `products.json`，访问速度快，不依赖实时后端。
- **傻瓜式操作**：输入型号即可生成初稿，适合门店员工快速使用。
- **精细化控制**：支持进一步调整文字、颜色、图标、价格、规格、布局和打印效果。
- **照片生成模板**：支持浏览器本地 OCR；识别不理想时可由用户主动使用 AI 深度识别。
- **可视化编辑**：支持文字、价格、卖点、颜色、规格等模块的拖拽和编辑。
- **多格式导出**：支持导出 PNG、PDF，也支持浏览器打印。
- **批量数据更新**：可通过 GitHub Actions 定时刷新产品数据。
- **适合 Cloudflare Pages 部署**：前端静态托管，部署成本低。

## 数据原则

本项目的数据处理原则：

- **官网优先**：商品标题、SKU、官方价格、颜色、硬件参数以品牌官网/官方商城为准。
- **辅助验证**：知乎 API 搜索结果仅作为全网信息补充和卖点参考。
- **人工可编辑**：生成结果不是最终强制内容，用户可以在页面中手动修正。
- **避免混淆型号**：对相近型号做严格匹配，减少 `Pro`、`i`、`s` 等后缀造成的误用。
- **品类可扩展**：不同品牌、不同品类可以接入独立的数据整理逻辑和价签模板。

安装依赖：

```powershell
npm install
```

如需在本地测试“AI 深度识别”，复制 `.env.example` 为 `.env`，填写 `FASTAPI_API_KEY` 后运行：

## 产品数据更新

型号清单在：

```text
data/models.txt
```

手动生成静态产品数据：

```powershell
node server.mjs --build-data
```

自动发现官网产品列表里的新增型号，并合并到型号清单：

```powershell
node server.mjs --discover-models
```

发现新型号后再刷新静态产品数据：

```powershell
npm run data:refresh
```

如果新机先上官网链接但暂未公布价格，静态库会先收录该产品并标记为“价格待公布”；发布会后官网放出价格/SKU，下一次刷新会自动补齐。

为降低官网访问压力，日常任务不会每天全量刷新所有旧型号：

- 新发现型号：当天抓取
- 价格待公布型号：每天重试
- 已有价格的旧型号：默认最多每天刷新 20 个，约 5 天轮换一遍
- 必要时全量刷新：`npm run data:build:full`

生成结果：

```text
public/data/products.json
```

大疆产品使用独立静态库，因为套装、遥控器、配件和 DJI Care 随心换价格体系不同：

```text
data/dji-products.txt
public/data/dji-products.json
```

手动刷新大疆静态库：

```powershell
npm run data:dji
```

线上部署时，GitHub Actions 会定时运行数据更新任务，并把新的 `products.json` 提交到仓库。
